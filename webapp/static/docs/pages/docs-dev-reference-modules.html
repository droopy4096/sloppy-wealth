Code map

Python 3, standard library plus Flask (webapp/requirements.txt). All code is under webapp/.

Dependency direction

browser (web/static/web.js, sessionStorage)
   │  form posts
   ▼
web/  (pages.py, client.py, timeline_draw.py, templates/)   no engine imports
   │  client.call / client.get  (in-process or WEB_API_URL)
   ▼
api.py  (/api/...)  + schema.py, timeline.py
   │
   ▼
state_machine/  (engine: ops, views, engine facade, compiler, runner, ...)
   │
   ▼
state_machine/jurisdictions/<code>/  (country rules, plug-ins)

web/ talks only to the API. api.py, schema.py and timeline.py import the engine. Inside the engine, plug-in modules (holdings/, flows/, events/, rules/, jurisdictions/) import the core; the core never imports a plug-in by name (they are found by compiler.discover()).

Month order

Every emitter has the key (order, ordinal, sub); the runner fires them in key order (clock.py). ordinal is the item index (for holdings and their modifiers: the holding's slot; -1 for scenario-level emitters). Steps are 100 apart:

OrderValueWhat runs
INITIAL-100Once before the first month: holdings that exist at the start (accounts, pensions, assets bought before).
OPEN0Household.begin_month (not an emitter); RetirementEmitter.
(OPEN + 50)50CA contribution room start and yearly room.
(OPEN + 59)59Trigger log entries.
(OPEN + 60)60Cash-flow adjustment log entries.
INCOME100Income, associated income and one-offs.
PENSION_PAY200Pension payments.
ACQUIRE300Purchases, loan advances, account openings.
IMPROVE400Improvements.
ADJUST500Market adjustments.
SELL600Sales, loan payoffs, sale penalties.
TRANSFER700One-off transfers.
SERVICE_DEBT800Per mortgage: renewal, interest and payment, then extra payments and lump sums.
EXPENSE900Expenses, associated expenses and costs.
MAINTAIN1000Unused (vehicle maintenance is now an associated expense).
CONTRIBUTE1100Contributions.
WITHDRAW1200Withdrawals.
GROW1300Appreciation and account returns on opening balances.
REVALUE_PENSIONS1400Pension revaluation.
TAX1500Tax step.
(TAX + 50)1550Cash balance reconciliation.
CLOSE1600Results row and holdings points.
